Task description:
I run an online community forum and I want a pipeline that predicts which new threads will become engaging so moderators can prioritize highlighting them. Features: opening post length, presence of specific content cues (questions, lists, media), poster's historical activity, time of posting, topic tags. Train a classifier on historical data labeled by "engagement at 48 hours" (comment count, vote count). Output is a per-new-thread score with contributing factors.
